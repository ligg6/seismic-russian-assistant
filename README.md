# 海洋地震俄语写作助手 · Морская сейсморазведка по-русски

面向中国地球物理研究生的**中俄专业翻译与俄语论文写作辅助工具**。单文件网页，无需安装，打开即用：

**在线使用** → https://ligg6.github.io/seismic-russian-assistant/

## 功能

| 页签 | 内容 |
|------|------|
| 术语查询 | 223 条海洋地震专业术语，中/俄/英三语搜索（变格形式、推荐用法、常见搭配、自创例句、证据等级、来源论文），一键导出 Anki 卡组 |
| 格支配·搭配 | 25 组动词/动名词格支配与自然搭配速查 |
| 句型模板 | 17 个论文章节（摘要、方法、处理流程、速度分析、偏移成像、质控、解释、讨论、结论…）的可复制句型 |
| 纠错对照 | 23 组中式俄语 → 自然学术俄语修正 |
| 翻译助手 | 粘贴中文内容 → 自动匹配库内标准术语 → 生成带术语约束和写作规则的完整提示词，复制给任何 AI 即产出论文级俄语 |
| 写作向导 | 11 个"文体×章节"套件（期刊摘要/引言/方法/结果/结论 + 博士绪论/综述/方法章），一页聚合该章所需句型/段落/表达 |
| 初稿体检 | 粘贴俄语初稿，即时分级检查 34 类已知问题（术语误写、格支配、口语化、过度断言、мы 密度、超长句…） |

## 数据来源

基于 40 篇俄语论文 + 17 部学位论文 + Йылмаз《Обработка сейсмических данных》俄译本 + Шалаева/Старовойтов《Основы сейсмоакустики на мелководных акваториях》教材的语料分析。每条术语带证据等级（high ≥5 篇论文 / medium ≥3 篇 / low）与来源编号；自创例句均标注需俄罗斯母语者确认。

## 文件

- `index.html` — 完整网页（自包含，可离线使用，直接双击打开）
- `template.html` + `webapp_data.json` — 模板与数据（由语料项目脚本自动生成）
